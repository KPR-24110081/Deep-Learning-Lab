# Deep Learning Laboratory

This repository contains a complete collection of deep learning lab assignments completed as part of the B.Tech Artificial Intelligence & Data Science curriculum at Shiv Nadar University Chennai. Each experiment explores a distinct area of deep learning, from perceptrons and CNNs to recurrent networks, transfer learning, and generative modeling.

## Repository overview

| Experiment | Topic | Focus area |
| --- | --- | --- |
| Ex-1 | Single-Layer Perceptron | Binary classification with a custom perceptron |
| Ex-2 | Multi-Layer Perceptron | Fashion-MNIST classification and hyperparameter tuning |
| Ex-3 | CNN Fundamentals | Convolution, pooling, padding, and CIFAR-10 classification |
| Ex-4 | Transfer Learning | Fine-tuning MobileNetV2 on CIFAR-10 |
| Ex-5 | Advanced CNN Study | Regularization, normalization, optimizers, transfer learning, and cross-validation |
| Ex-6 | Recurrent Neural Networks | RNN, LSTM, GRU, and Seq2Seq sequence modeling |
| Ex-7 | Autoencoders & VAEs | Denoising, reconstruction, latent space, and generative modeling |

## Getting started

1. Clone the repository.
2. Open the desired experiment folder.
3. Launch the notebook using Jupyter Notebook or JupyterLab.
4. Run the cells sequentially to reproduce the training, evaluation, and visualization steps.

## Notes

- Some datasets are loaded dynamically during execution and may need internet access or a local dataset cache.
- Generated plots and reports are included in the experiment folders for quick inspection.
- Each folder contains a dedicated README with experiment-specific objectives, setup, and findings.
